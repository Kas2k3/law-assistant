`chatbot-group14`, ngày 2026-10-17, không giữ lịch sử git).

| Tài liệu | Nội dung |
|---|---|
| [`ARCHITECTURE.md`](./ARCHITECTURE.md) | Phân tích chi tiết kiến trúc hiện trạng: data layer, ingestion, retrieval, pre-retrieve agents, agentic RAG core, API, frontend, persistence, evaluation, hạ tầng, và danh sách khoảng trống/nợ kỹ thuật |
| [`PROPOSAL_SUMMARY.md`](./PROPOSAL_SUMMARY.md) | Tóm tắt lại `Proposal.docx` (đề tài gốc) dưới dạng text dễ tra cứu + nhận định khoảng cách giữa proposal và hệ thống hiện có |
| [`DEVELOPMENT_PLAN.md`](./DEVELOPMENT_PLAN.md) | Kế hoạch phát triển chi tiết theo từng giai đoạn (Phase 0–6) để đưa hệ thống về đúng trọng tâm nghiên cứu mà proposal yêu cầu: chunking/embedding ablation, đánh giá retrieval đúng pipeline, đánh giá chất lượng câu trả lời, timeline, phân công, rủi ro |

Đọc theo thứ tự: `ARCHITECTURE.md` → `PROPOSAL_SUMMARY.md` → `DEVELOPMENT_PLAN.md`.
